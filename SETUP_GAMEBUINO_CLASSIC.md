# Setup Gamebuino Classic

## What Students Need

- Gamebuino Classic
- USB cable
- computer with Arduino IDE or a teacher-approved Arduino CLI setup
- Gamebuino Classic library
- optional micro SD card

## Teacher Prep Checklist

- Charge devices.
- Label devices.
- Test one upload per computer type.
- Prepare backup starter sketches.
- Prepare spare USB cables.
- Print or share `TROUBLESHOOTING.md`.

## Student Setup

1. Install or open Arduino IDE.
2. Install the Gamebuino Classic library.
3. Open `projects/00_welcome_badge/welcome_badge.ino`.
4. Select the teacher-verified board and port.
5. Compile.
6. Upload.
7. Run the sketch on the Gamebuino Classic.

## Needs Teacher Verification Before Class

Classic setup can vary by device batch, school computer policy, operating system, and installed Arduino tooling. Before class, verify the exact board, port, upload settings, and library installation path on the actual devices. Add screenshots or school-specific steps here after verification.

Do not substitute Gamebuino META setup steps or Python instructions.
