# Solution Strategy

The public repo should not contain full solutions for every lesson. Students need enough support to continue independently, but not a nearby answer key that turns the course into copy/paste.

## Recommended Setup

- Keep public files as starters, snippet cards, debug puzzles, and checkpoints.
- Keep complete teacher solutions in a private branch, private repo, or local teacher ZIP.
- Release a reference sketch only after the class has built the underlying mechanics.
- When helping, reveal the smallest next expression, condition, or variable name.

## In-Class Rule

Students may use:

- lesson README snippet cards
- hints
- debug puzzles
- partner explanations
- official references during Code Archaeology

Students should not paste:

- whole finished sketches
- another student's finished project
- the Falling Stars reference before the reference lock opens

## Teacher Solution Branch

A private solution branch can mirror the public structure:

- `solutions/projects/05_moving_square/moving_square_solution.ino`
- `solutions/projects/11_falling_stars/falling_stars_solution.ino`
- `solutions/teacher-notes/misconceptions.md`

Keep that branch access-controlled. The student-facing repo stays clean.
