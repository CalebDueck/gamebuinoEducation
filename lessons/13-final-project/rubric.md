# Final Project Rubric

Scale: 1 = Not yet, 2 = Works with help, 3 = Works independently, 4 = Adds thoughtful power-ups.

- Core mechanics: input, visible player or cursor, and a clear goal.
- Code organization: at least one useful function and readable variable names.
- Player feedback: score, lives, timer, progress, sounds, or messages.
- Customization: student-made sprite, theme, rules, or polish.
- Debugging/polish: tested by someone else and improved.
- README/communication: controls, goal, credits, and customization notes.
