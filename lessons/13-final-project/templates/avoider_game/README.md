# Avoider Game

Starter file: `avoider_game_starter.ino`

This starter is intentionally incomplete. You still need to write the movement, hazard, and lose-condition logic yourself.

Build the smallest version first:

- Move a player left and right.
- Make one hazard move toward the player.
- Lose a life or end the run on collision.
- Restart from a title or game-over screen.

Customization ideas:

- Change the hazard theme: rocks, raindrops, lasers, or enemies.
- Increase speed over time.
- Add score for surviving longer.
