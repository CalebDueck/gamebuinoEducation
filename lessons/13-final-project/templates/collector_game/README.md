# Collector Game

Starter file: `collector_game_starter.ino`

Build the smallest version first:

- Move a player with the D-pad.
- Collect one moving or stationary item.
- Increase score when the item is collected.
- Reach a win score or add a game-over rule.

Customization ideas:

- Change the item theme: coins, stars, snacks, or keys.
- Add a timer or lives.
- Add a second item type worth more points.
