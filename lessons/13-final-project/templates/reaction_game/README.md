# Reaction Game

Starter file: `reaction_game_starter.ino`

Build the smallest version first:

- Show one target button.
- Give the player a short time to react.
- Award a point for a correct press.
- End the round after a mistake or after several turns.

Customization ideas:

- Speed up after each success.
- Use A, B, and C for harder rounds.
- Add a best score challenge.
