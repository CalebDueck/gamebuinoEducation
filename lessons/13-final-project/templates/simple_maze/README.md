# Simple Maze

Starter file: `simple_maze_starter.ino`

Plan a tiny maze where the player reaches an exit without touching walls.

Required ideas:

- D-pad movement.
- Walls or obstacles.
- A start, win, or game-over state.
- The README explains the goal and controls.

Customization ideas:

- Add a timer.
- Add moving hazards.
- Add a key before the exit opens.
