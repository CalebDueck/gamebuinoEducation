# Teacher Notes - Move Your Sprite

## What To Watch
Students should complete the mission by changing small pieces, not by importing a finished sketch. Ask them to point to the line that creates the checkpoint behavior.

## Good Questions
- What did you predict before upload?
- Which variable changed?
- Which function owns that behavior?
- What is the smallest test you can run next?

## Intervention Ladder
1. Ask for the expected behavior.
2. Ask for the exact line responsible.
3. Offer the snippet card from the README.
4. Reveal only the next expression or condition, not the whole sketch.

## Extension
Use the Challenge Quest when a student can explain the checkpoint without reading their code line by line.
