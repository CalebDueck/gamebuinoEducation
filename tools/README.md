# Tools

These Python tools and tests use only the Python standard library.

- `sprite_validator.py`: checks `.sprite.txt` files.
- `sprite_preview.py`: prints a terminal preview or writes an SVG preview.
- `sprite_to_bitmap.py`: converts ASCII sprites to Gamebuino Classic bitmap headers.
- `build_gallery.py`: combines class submissions into a gallery header and index.
- `check_lesson_structure.py`: keeps lesson folders complete and programmer-facing READMEs starter-focused.
