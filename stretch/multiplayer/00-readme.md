# Multiplayer Stretch

Use this stretch only after the core single-player lessons are comfortable.

What this stretch is for:

- sending simple data between two Gamebuino Classic devices
- separating master and slave roles
- testing multiplayer one behavior at a time

Suggested order:

1. `01-two-device-handshake.md`
2. `02-remote-button-viewer.md`
3. `03-two-player-pong.md`

Safety: only connect Gamebuino consoles using the correct verified I2C hardware. Power off before changing cables.
