# Read Pong

Official example:

- https://raw.githubusercontent.com/Gamebuino/Gamebuino-Classic/master/examples/3.Advanced/PongMulti/PongMulti.ino

Read the main sketch, but focus on the basic Pong parts first.

Focus questions:

- Which variables store paddle and ball position?
- Which function updates movement?
- Which function draws the game?
- Where does score change?

What to notice:

- larger sketches split jobs across more than one file
- games often separate update rules from draw rules
- ball speed and paddle speed usually come from a few variables

Small change ideas:

- slow the ball down
- make paddles taller
- change the score needed to win

Checkpoint:

- You can identify one movement rule and one drawing rule.
