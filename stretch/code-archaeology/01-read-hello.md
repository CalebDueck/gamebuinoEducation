# Read Official Hello

Official example:

- https://raw.githubusercontent.com/Gamebuino/Gamebuino-Classic/master/examples/1.Basics/a_Hello/a_Hello.ino

Focus questions:

- Where does the sketch start?
- Which line prints text to the screen?
- Which parts run once and which parts repeat?

What to notice:

- `setup()` prepares the Gamebuino.
- `loop()` keeps running.
- The example is tiny because it teaches one behavior at a time.

Small change ideas:

- change the shown text
- add one more printed line
- move one printed line by changing its position

Checkpoint:

- You can point to the line that draws text.
- You can explain why the text appears again each frame.
