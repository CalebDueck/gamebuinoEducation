# Code Archaeology

Use this stretch path after the core lessons when you want to study how official Gamebuino examples are organized.

What this stretch is for:

- reading real example code without copying whole sketches
- naming one behavior before you run the code
- finding which function or variable owns that behavior
- making one very small change and testing it

How to use these files:

1. Pick one numbered archaeology mission in this folder.
2. Open the official example link written directly in that mission file.
3. Predict one behavior before you compile or run anything.
4. Find the exact line or function that causes that behavior.
5. Make one tiny change and test it.

Rule:

- Do not paste the official example into a core lesson.
- Use the example to learn structure, naming, and small patterns.
