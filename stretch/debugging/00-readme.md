# Debugging Stretch

This is a stretch quest. The sketch in this folder is intentionally broken.

Your job is to make it match the expected behavior without getting line-by-line hints about what is wrong.

Use this process:

1. Read the expected behavior first.
2. Compile and read the first error.
3. Fix one problem.
4. Compile again.
5. When it uploads, test the live behavior on the Gamebuino.

Do not rewrite the whole sketch from scratch. Repair the existing code one small step at a time.
