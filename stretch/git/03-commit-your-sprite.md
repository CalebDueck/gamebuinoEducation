# Git Mission 3 - Commit Your Sprite

Use this stretch after you have made your own sprite file.

Goal:

- save your sprite work as a Git commit with a useful message

For sprite gallery work:

- create your own `.sprite.txt` file under `class_gallery/submissions/`
- run `python tools/sprite_validator.py your_file.sprite.txt` before committing

Then:

1. Run `git status` and confirm only your intended files changed.
2. Run `git add <your-file>`.
3. Run `git commit -m "Add my sprite"`.

Checkpoint:

- the sprite validates
- Git records one commit with your change
