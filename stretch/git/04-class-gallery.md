# Git Mission 4 - Sprite Gallery

Use this stretch when you want to contribute one sprite to the class gallery.

Goal:

- add one validated sprite file that can be included in the gallery build

The sprite gallery uses one `.sprite.txt` file per gameBuilder inside `class_gallery/submissions/`.

Before adding your gallery contribution:

- make sure you are editing only your own file
- validate it with `python3 tools/sprite_validator.py your_file.sprite.txt`

Then:

1. Give the file a clear name.
2. Keep the sprite dimensions valid.
3. Commit only your own submission.
4. If your class uses the gallery generator, rebuild the gallery after the file is added.

Checkpoint:

- your sprite file is valid
- your file is ready to be included in the class gallery
