# Git Mission 1 - Clone the Repo

Use this stretch if you are ready to keep your own copy of the course with Git.

Goal:

- make a local copy of the repo that you can edit safely

Steps:

1. Install Git if it is not already on your computer.
2. Copy the repo URL.
3. Run `git clone <repo-url>`.
4. Open the cloned folder.
5. Confirm you can see `README.md`, `lessons/`, and `stretch/`.

Checkpoint:

- the repo exists on your machine in its own folder
- you can open the cloned copy and browse the lesson files
