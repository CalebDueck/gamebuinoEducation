# Git Mission 2 - Run the Reward Project

Use this stretch after cloning the repo.

Goal:

- open a project from the repo, run it, and prove your local copy works

Steps:

1. Choose one known sketch from the repo.
2. Open it in Arduino IDE.
3. Compile it.
4. Upload it to the Gamebuino.
5. Make one tiny visible change and upload again.

Good tiny changes:

- change a title
- change a popup message
- move one shape a few pixels

Checkpoint:

- you ran a sketch from your cloned repo
- you changed one visible behavior in your own copy
